# ATV Dubai Guide - React Website

A React 19 + Vite web application recreating the luxury **ATV Dubai Guide** desert experience hero section with cockpit POV framing, digital dashboard cluster, and interactive booking system.

## 🚀 Quick Start

### 1. Start Development Server
```bash
npm run dev
```
The app will be running at `http://localhost:3000`.

### 2. Build for Production
```bash
npm run build
```
Generates the optimized production bundle in `/dist`.

### 3. Preview Production Build
```bash
npm run preview
```

---

## 📁 Component Structure
- `src/App.jsx` - Root application coordinating parallax, state, and layouts.
- `src/components/Header.jsx` - Integrated cockpit top visor navigation & mobile drawer.
- `src/components/Dashboard.jsx` - Digital gauge cluster with live speed, clock, ride mode cycler, and 4WD lock.
- `src/components/FleetSelector.jsx` - Vehicle selection quick pills.
- `src/components/Modals.jsx` - Video Tour popup and VIP Reservation modal with real form state.
- `src/index.css` - Custom styling matching the cockpit styling.
- `public/` - High-resolution cockpit background and brand assets.
